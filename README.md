# 범양 현장훈련장

신규 입직자를 위한 PC 브라우저용 3D 보행·건설장비 자유 조작 게임입니다. React UI와 Three.js 장면을 분리했고, 현장은 직접 만든 로우폴리 형상과 오후의 따뜻한 조명으로 구성했습니다.

## 실행

Node.js 22.13 이상에서:

```sh
npm ci
npm run dev
```

개발 서버가 출력하는 주소로 접속합니다. `npm run build`는 Sites용 Worker와 클라이언트를 생성합니다. `npm start`는 생성된 Worker를 로컬에서 실행합니다.

## 조작

| 상태 | 키 | 동작 |
|---|---|---|
| 도보 | WASD / Shift | 화면 기준 이동 / 달리기 |
| 공통 | F | 가까운 장비 탑승 / 안전한 옆 공간으로 하차 |
| 공통 | V | 기존 탑뷰 / 1인칭 모드 전환 |
| 1인칭 도보 | 마우스 드래그 / 방향키 | 좌우·상하 둘러보기 |
| 장비 | W S / A D | 전·후진 / 조향 |
| 장비 | Q E | 상부 선회 |
| 장비 | ↑ ↓ | 붐 또는 가이드 각도 |
| 장비 | T G | 와이어 권상 / 하강 |
| 커터 | Z | 커터 회전 켜기 / 끄기 |
| 그랩 | Z X | 그랩 닫기 / 열기 |
| 장비 | Space | 누르는 동안 주행·조작 정지, 커터 회전 종료 |
| 공통 | M / C / 휠 | 전체 지도 / 90도 시점 회전 / 확대·축소 |
| 공통 | H / Esc / Tab | 도움말 / 일시정지 / 장비 목록 접기 |

왼쪽 장비 목록은 위치를 안내합니다. 탑승은 현장에서 장비에 접근한 후 가능합니다. 소리는 우측 상단 버튼으로 켤 수 있습니다. 저장 계정이나 외부 AI 서비스 없이 브라우저 안에서 실행되며, 새로고침 시 초기 상태로 돌아갑니다.

1인칭 모드에서는 도보 카메라가 고정 눈높이에서 보는 방향으로 움직입니다. 장비에 타면 차체 뒤를 가까이 따라가는 원근 TPS 시점로 자동 전환하고, 하차하면 이전 시선의 1인칭으로 돌아옵니다. 전체 지도도 이전 시점을 보존합니다. 1인칭에서 방향키는 시선 조작이며, 탑승 후 위·아래 키는 기존 붐 조작으로 전환됩니다. V 또는 오른쪽 위 버튼으로 기존 탑뷰를 언제든 선택할 수 있습니다.

## 구현 범위와 자료 근거

- 180 × 140 m 현장: 깊이 있는 굴착부, PPS 스트럿, 연속벽, 현장사무소, 슬러리 처리 설비, 사일로, 자재장, 주변 도로·건물.
- 탑승 장비 4종: 현장 이동용 트럭, CX 1200HD-2 크롤러 크레인, SC40 트렌치 커터, HSG 5-18L 하이드로 그랩.
- 24명의 자율 작업자: 자재 운반, 현장 감독, 신호수, 설비 점검. 지정 경로와 대기·회피 규칙으로 움직입니다.
- 자율 순회 장비 4대: 지게차 2대, 소형 굴착기 2대. 작업자에게 양보하고, 길이 계속 막히면 돌아갑니다. 플레이어 탑승 대상은 아닙니다.
- 트럭은 W/S 가속·후진, A/D 속도에 따른 조향, Space 즉시 제동으로 조작합니다. 건설장비의 선회·붐·와이어 기능은 없습니다.
- 보행 속도 6.24 m/s, 달리기 11.05 m/s로 종전 대비 각각 30% 증가했습니다.
- 보행·장비의 난간, 건물, 적치물, 타 장비 충돌 검사. 장비 주행은 가까운 작업자를 피하고, 하차 지점도 충돌 없이 선택합니다.
- 사용자 제공 `Company_BroshureKOR-2.pdf`의 장비 현황 인쇄 p.10–13, PPS 시공사례 p.26–27 참고. PDF 파일 기준으로는 6–7, 14페이지입니다.
- 실제 현장 사진의 구조와 장비 목록을 참고한 합성 현장입니다. 특정 현장을 측량해 복제한 디지털 트윈이 아니며, 장비 형상·작동 범위는 게임용으로 단순화했습니다. 정밀 물리, 하중, 토질, 면허·법정교육 인증은 구현하지 않았습니다.
- 요청 범위에 따라 굴착·양중 등의 목표 과업, 점수, ESG 대시보드는 포함하지 않았습니다.

## 로고 출처와 렌더링

좌측 하단 로고는 사용자 제공 브로슈어 표지의 34개 원본 벡터 경로를 추출한 SVG입니다. 심볼, 한글 회사명, 영문 글자의 윤곽과 색상을 보존했습니다. PDF 원본은 저장소에 포함하지 않습니다. 회사 로고의 권리는 해당 권리자에게 있습니다.

캐릭터 이름표는 React 상태 갱신과 분리하여 매 프레임 CSS transform으로 배치합니다. 장비의 고정 부품은 관절별로 병합하고, 작업자는 역할·관절별 InstancedMesh로 렌더링합니다. 그림자는 최대 30회/초 갱신하며 기존 4096 해상도를 유지합니다. 계기판은 8회/초 갱신하고, 소리 매개변수의 예약 호출도 제한했습니다.

## 확장 지점

`lib/field/catalog.ts`는 장비·구역 데이터, `world.ts`는 환경·충돌, `actors.ts`는 장비 관절과 작업자, `engine.ts`는 입력·카메라·시뮬레이션을 담당합니다. UI는 `app/page.tsx`에 있습니다.

`pumyang:simulation` 이벤트는 장비 탑승·하차를 전달합니다. 후속 작업 시스템은 장비 ID와 시뮬레이션 시간을 바탕으로 과업 조건을 추가할 수 있습니다. 자재 부착·분리, 굴착 면 변화, 신호수 지시 준수 판정은 별도 작업 시스템으로 확장하는 것을 권장합니다.

지원 브라우저에는 WebMCP 읽기·위치 안내·탑승·키 입력 도구도 등록됩니다. 실제 사용자 입력과 동일한 충돌·조작 경로를 사용하며, 지원하지 않는 브라우저에서는 일반 게임 기능에 영향이 없습니다.

## 검증

```sh
npx tsc --noEmit
npm run lint
npm test
npm run build
```

Lint는 직접 작성한 `app`, `lib`, `qa`를 검사합니다. 사용하지 않은 초기 shadcn 예제 컴포넌트는 이 검사 범위에서 제외했습니다. 브라우저 플레이 점검과 시각 개선 기록은 `qa/REVIEW.md`, 실제 캡처는 `qa/screenshots/`에 있습니다.
